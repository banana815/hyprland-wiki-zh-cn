    请先确认文档版本

    这份 Wiki 按版本提供文档。默认显示的内容对应 Hyprland 最新的 Git 提交。你很可能安装的是带版本标签的发行版。可以运行 hyprctl version 查看版本号，再从版本选择器中选择对应的文档。

    先看看常见问题和配置指南，里面很可能已经介绍了你遇到的问题。要是还没找到答案，可以搜索 GitHub 讨论区，也可以到 Hyprland 社区求助。

    关于 Wayland

    Wayland 合成器本身就是一个独立运行的显示服务器，和 Xorg 一样。在 Xorg 上，你可以自由搭配窗口管理器和合成器。在 Wayland 上，合成器之间无法这样混搭。

    并非所有 Xorg 应用都能在 Wayland 上运行，也不建议尝试把它们全部搬过来。你可以在实用工具中找到推荐的 Wayland 原生应用和兼容程序。
