# hyprland-qt-support

[hyprland-qt-support](https://github.com/hyprwm/hyprland-qt-support) 为 hypr\* 系列的 Qt 6 应用程序提供 QML 样式。

<a id="configuration"></a>

## 配置

配置文件位于 `~/.config/hypr/application-style.conf`。

| 变量 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| `roundness` | 界面元素的圆角程度。取值范围：[0 - 3] | int | `1` |
| `border_width` | 界面元素的边框宽度。取值范围：[0 - 3] | int | `1` |
| `reduce_motion` | 减少界面元素的动态效果（如过渡动画、悬停效果等）。 | bool | `false` |
