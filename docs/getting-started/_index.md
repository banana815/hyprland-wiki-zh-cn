# 入门指南

如果你是第一次使用 Hyprland，请先阅读[安装](installation.md)页面。

安装 Hyprland 后，请阅读[主教程](master-tutorial.md)。

> [!WARNING]
> Hyprland 的设计目标并不是提供一个完整、易用的桌面环境。
> 简单来说，它是一套让你构建自己的桌面环境的工具。
>
> 应用、集成组件、Shell 等都需要**你自己**选择、安装和配置。
>
> 这份 Wiki 写得_非常_详细。
> 在断定某项功能无法正常工作或根本不存在之前，强烈建议你先仔细查找并阅读 Wiki 中的相关内容。

> [!NOTE]
> NVIDIA 显卡往往无法开箱即用。
> 如果你打算使用 NVIDIA 显卡，请在安装 Hyprland 后按照 [NVIDIA 页面](../nvidia/_index.md)上的说明操作。
> 这得怪 NVIDIA。
