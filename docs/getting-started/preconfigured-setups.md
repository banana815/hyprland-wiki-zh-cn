# 预配置方案

> [!WARNING]
> 为了按预期运行，许多配置方案在安装时会深入系统，进行大幅修改。
> 如果以后想移除这些配置，可能会比预想中更困难。
> 即使配置方案自带卸载脚本，也可能清理不彻底。

不想花好几天从零开始把 Hyprland 调到称心如意，希望一开始就能用上类似完整桌面环境的配置？
你来对地方了。

下面有几种方案可供选择：

<a id="omarchy-sponsored"></a>

## Omarchy <span style="color: gray; font-size: 12px;">赞助</span>

DHH 按自己的使用理念打造的 Arch + Hyprland 配置方案。

[官网](https://omarchy.org/)

![Omarchy 桌面截图](https://i.ytimg.com/vi/Cft6mZDzIng/maxresdefault.jpg)

<a id="ml4w"></a>

## ML4W

ML4W（My Linux 4 Work）由 Stephan Raabe 打造，开箱即用，能带来出色的桌面环境体验。

它提供简单易用的图形化设置工具、预先配置好且功能丰富的面板、欢迎应用等。

[官网](https://ml4w.com/os/)

[GitHub](https://github.com/mylinuxforwork/dotfiles)

[YouTube](https://www.youtube.com/@mylinuxforwork)

![ML4W 配置文件的桌面效果图](https://i.ibb.co/fYj49BRB/screen-215.jpg)

喜欢用终端？

<a id="dank-linux"></a>

## Dank Linux

Dank Linux 是一套围绕 DankMaterialShell 构建的桌面套件。DankMaterialShell 是一个完整的桌面外壳，设计灵感来自 Material 3。
在许多常见发行版上，只需运行一条安装命令，就能为现有系统配好风格统一的 Hyprland 桌面，包含桌面栏、启动器、通知、锁屏和控制中心，还能根据壁纸自动调整主题。

[官网](https://danklinux.com/)

[GitHub](https://github.com/AvengeMedia/DankMaterialShell)

![Dank Linux 桌面截图](https://github.com/user-attachments/assets/203a9678-c3b7-4720-bb97-853a511ac5c8)
