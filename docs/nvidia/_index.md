# NVIDIA

<a id="foreword"></a>

## 前言

如果你的 NVIDIA GPU 型号较新，支持开源内核模块，我们建议使用官方专有驱动并搭配开源内核模块，以获得最佳性能。

由于官方驱动仍是专有软件，在 Hyprland 上使用 NVIDIA GPU 时，可能会遇到一些我们无法控制的问题。
不过，驱动正在缓慢而稳步地改进。现在已经可以配置出运行良好的系统，使用体验几乎能与 AMD 和 Intel GPU 媲美。

<a id="wiki-links"></a>

## Wiki 链接

NVIDIA 驱动的配置步骤因发行版而异。
要获取适合你的发行版和 GPU 组合的最新推荐驱动安装指南，请参阅所用发行版 Wiki 中的 NVIDIA 页面。
以下是我们正式支持的发行版对应的 Wiki 页面：

- [Arch Wiki](https://wiki.archlinux.org/title/NVIDIA)
- [NixOS Wiki](https://wiki.nixos.org/wiki/NVIDIA)
