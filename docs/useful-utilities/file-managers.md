# 文件管理器

<a id="gui"></a>

## 图形界面（GUI）

- [dolphin](https://github.com/KDE/dolphin)：KDE 的文件管理器。
- [nautilus](https://apps.gnome.org/en/Nautilus/)：GNOME 的文件管理器。
  - [nautilus-admin-gtk4](https://github.com/MacTavishAO/nautilus-admin-gtk4)：以更高权限打开文件。
  - [nautilus-image-converter](https://gitlab.gnome.org/coreyberla/nautilus-image-converter)：调整图片大小和旋转图片。
  - [nautilus-open-any-terminal](https://github.com/Stunkymonkey/nautilus-open-any-terminal)：在选中的目录中打开终端。
- [nemo](https://github.com/linuxmint/nemo)：Cinnamon 的文件管理器。
  - [nemo-fileroller](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-fileroller)：文件归档扩展。
  - [nemo-terminal](https://github.com/linuxmint/nemo-extensions/tree/master/nemo-terminal)：内嵌终端窗口。
- [pcmanfm-qt](https://github.com/lxqt/pcmanfm-qt)：LXQt 的文件管理器。
- [pcmanfm](https://github.com/lxde/pcmanfm)：LXDE 的文件管理器。
- [thunar](https://gitlab.xfce.org/xfce/thunar)：Xfce 的文件管理器。

<a id="tui"></a>

## 文本界面（TUI）

- [lf](https://github.com/gokcehan/lf)：用 Go 编写的文件管理器，设计上大量借鉴了 ranger。
- [nnn](https://github.com/jarun/nnn)：n³，一款与众不同的终端文件管理器。
- [ranger](https://github.com/ranger/ranger)：受 Vim 启发的控制台文件管理器。
- [superfile](https://github.com/yorukot/superfile)：一款界面精美的现代终端文件管理器。
- [yazi](https://yazi-rs.github.io/)：用 Rust 编写、基于异步 I/O 的高速终端文件管理器。
