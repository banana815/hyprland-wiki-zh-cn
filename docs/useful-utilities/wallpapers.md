# 壁纸

将壁纸工具加入 Hyprland 配置的自动启动项，让它随 Hyprland 一起启动。

<a id="hyprpaper"></a>

## hyprpaper

`hyprpaper` 是 Hypr 开发团队自家开发的壁纸工具。
使用和配置方法请见[这里](../hypr-ecosystem/user/hyprpaper.md)。

<a id="swaybg"></a>

## swaybg

如果只想设置一张简单的静态壁纸，swaybg 很合适。
[GitHub](https://github.com/swaywm/swaybg)

<a id="wpaperd"></a>

## wpaperd

一款功能稍丰富的壁纸守护进程，提供自动更换壁纸等进阶功能。
[GitHub](https://github.com/danyspin97/wpaperd)

<a id="mpvpaper"></a>

## mpvpaper

一款小巧的 mpv 封装工具，可将视频作为壁纸播放。
[GitHub](https://github.com/GhostNaN/mpvpaper)

> [!TIP]
> 壁纸处于后台时，可以用 [mpvpaper-stop](https://github.com/pvtoari/mpvpaper-stop) 暂停播放，以节省系统资源和电量。

<a id="awww"></a>

## awww

一款高效的 Wayland 动态壁纸守护进程，支持在运行时进行控制，无需重启就能更换壁纸。
[Codeberg](https://codeberg.org/LGFae/awww)

<a id="waypaper"></a>

## waypaper

一款带图形界面的壁纸管理器，可直观地选择静态或动态壁纸，在 Wayland 上支持使用 `swaybg` 和 `awww` 作为后端。
[GitHub](https://github.com/anufrievroman/waypaper)

<a id="wallrizz"></a>

## wallrizz

一款带终端界面的壁纸管理器，可直观地选择并应用桌面壁纸。
在 Wayland 上，它支持 `awww`、`hyprpaper` 等多种后端。
[GitHub](https://github.com/5hubham5ingh/WallRizz)
