<a id="using-hyprland-on-any-other-distro-with-the-nix-package-manager"></a>

## 在其他发行版上通过 Nix 包管理器使用 Hyprland

如果你想使用 Hyprland，但所用的发行版未获官方支持，可以单独安装 Nix 包管理器。
这样使用 Hyprland 的体验更好，也能确保用上最新版本，尤其是在采用固定版本发布模式的发行版上。
这种方式也比从源码编译更简单，还能利用二进制缓存，这对配置较低的设备尤为重要。
请参阅[此页面](hyprland-on-any-distro-using-nix.md)。
