    应用启动器

    Hyprlauncher #

    Hyprlauncher 是 Hyprland 官方提供的多用途工具，既可作为启动器，也可作为选择器。 有关用法和配置，请参阅使用与配置说明。

    Rofi #

    Rofi 既是窗口切换器和应用启动器，也可替代 dmenu。 自 2025 年起，Rofi 支持 Wayland。 GitHub

    Wofi #

    Wofi 是一款基于 GTK、可自定义的 Wayland 启动器。 SourceHut

    bemenu #

    bemenu 是 dmenu 的 Wayland 原生替代品。 GitHub

    fuzzel #

    Fuzzel 是一款适用于基于 wlroots 的 Wayland 合成器的应用启动器，用法类似于 Rofi 的 drun 模式。 Codeberg

    tofi #

    tofi 可在基于 wlroots 的 Wayland 合成器中替代 dmenu 或 Rofi，速度极快、简单易用，而且支持高度自定义。 配置得当时，tofi 的界面可以在一帧之内显示出来。 GitHub

    Emacs #

    如果你已经在运行 Emacs 服务器，可以直接用 Emacs 启动应用。

    配置方法可参考 DistroTube 的 Configuring Emacs 或 Sebastian Wae 的 app-launcher 仓库。

    Anyrun #

    Anyrun 是一款类似 krunner 的 Wayland 原生启动器，设计时注重可定制性。 它采用模块化设计，可通过插件扩展。 启用 Applications 插件后，即可将它用作应用启动器。 GitHub

    Walker #

    Walker 是一款可扩展的 Wayland 原生启动器，内置多种模块（截至 2024-03-15，包括应用程序、命令运行器、Hyprland 窗口和网页搜索）。 它可以作为服务运行，以缩短启动时间。 GitHub

    Vicinae #

    Vicinae 是一款使用 C++ 和 Qt 开发的原生启动器，主要面向 Wayland。 它内置多种模块。 它以服务器形式在后台运行。 它通过兼容层支持 Raycast 扩展。 GitHub

    更完整的启动器列表见 awesome-hyprland。
