    其他

    这里列出了一些可能不属于上述任何类别的项目。

    工作区管理 #

    split-monitor-workspaces 由 Stanisław Zagórowski 开发： 为 Hyprland 提供类似 Awesome 的工作区。

    窗口切换器 #

    snappy-switcher 由 OpalAayan 开发： 适用于 Hyprland 的高速 Alt+Tab 窗口切换器，带有动画效果，用 C 编写（使用 Pango 和 Cairo）。

    键盘布局管理 #

    hyprland-per-window-layout 由 MahouShoujoMivutilde 和 coffebar 开发： 让 Hyprland 的每个窗口都能使用独立的键盘布局。

    编辑器对配置文件的支持 #

    HyprLS 由 gwennlbh 开发： 一款 LSP 服务器，在 Neovim、VS Code 等编辑器中为 Hyprland 配置文件提供自动补全等功能。

    键位绑定管理 #

    hyprKCS 由 kosa12 开发： 用 Rust 和 GTK4 编写的 Hyprland 键位绑定管理器，快速而精简。

    IPC 封装 #

    hyprland-rs 由 yavko 开发： 用 Rust 为 Hyprland 的 IPC 提供了简洁的封装。

    屏幕着色器与色温 #

    • hyprshade 由 loqusion 开发： 可手动或定时切换屏幕着色器，也可用作自动色温调节工具。
    • gammastep 由 Chinstrap 开发： 根据一天中的时刻和地理位置自动调节色温。

    无线设置 #

    • iwgtk 由 Jesse Lentz 开发： 用 GTK 编写的 iwd Wi-Fi 设置前端。
    • blueberry 由 Linux Mint 开发： 用 GTK 编写的蓝牙设置前端。
    • Overskride 由 kaii-lb 开发： 用 GTK4 编写的蓝牙客户端，简单易用，功能强大。
    • nm-applet 由 GNOME 开发： 用于与 NetworkManager 交互的 GTK 小程序。

    使用 udiskie 自动挂载设备 #

    启动方式： 手动配置（在 Hyprland 配置文件中添加自启动项）。

    USB 大容量存储设备（如 U 盘、手机和数码相机等）不会自动挂载到文件系统。

    通常需要手动挂载这些设备，常见做法是以 root 权限运行 mount。 许多流行的桌面环境通过封装 udisks2 的工具自动处理挂载。 udiskie 是 udisks2 的前端，可让你在用户空间管理光盘、U 盘等可移动介质。

    通过软件包管理器安装 udiskie，也可以手动构建。 打开 hyprland.lua，将 udiskie 加入自启动项。

    查看更多用法。
