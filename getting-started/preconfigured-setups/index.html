    预配置方案

    警告

    为了按预期运行，许多配置方案在安装时会深入系统，进行大幅修改。 如果以后想移除这些配置，可能会比预想中更困难。 即使配置方案自带卸载脚本，也可能清理不彻底。

    不想花好几天从零开始把 Hyprland 调到称心如意，希望一开始就能用上类似完整桌面环境的配置？ 你来对地方了。

    下面有几种方案可供选择：

    Omarchy 赞助 #

    DHH 按自己的使用理念打造的 Arch + Hyprland 配置方案。

    官网

    ML4W #

    ML4W（My Linux 4 Work）由 Stephan Raabe 打造，开箱即用，能带来出色的桌面环境体验。

    它提供简单易用的图形化设置工具、预先配置好且功能丰富的面板、欢迎应用等。

    官网

    GitHub

    YouTube

    end_4 #

    喜欢 Material 设计风格？ 想用上许多出色的应用？ 不介意稍微动手调一调？ end-4 可以满足这些需求。

    GitHub

    HyDE #

    偏爱简约、清爽又美观的桌面？ 喜欢用终端？ HyDE Project 的 HyDE 配置文件很受欢迎，也很适合你。

    GitHub

    Dank Linux #

    Dank Linux 是一套围绕 DankMaterialShell 构建的桌面套件。DankMaterialShell 是一个完整的桌面外壳，设计灵感来自 Material 3。 在许多常见发行版上，只需运行一条安装命令，就能为现有系统配好风格统一的 Hyprland 桌面，包含桌面栏、启动器、通知、锁屏和控制中心，还能根据壁纸自动调整主题。

    官网

    GitHub

    fufexan #

    https://github.com/fufexan/dotfiles

    coffebar #

    https://github.com/coffebar/dotfiles

    值得关注但已过时的配置方案 #

    JaKooLit #

    安装 JaKooLit 的配置文件也是个不错的选择。 这套配置同样功能丰富，维护得也很好。

    JaKooLit 为这套配置提供了适用于多种发行版的安装脚本，还有许多主题可供选择。

    YouTube
