    安装

    警告

    Hyprland 的设计目标并非提供一套完整易用的桌面环境。 简单来说，它是一组工具，供你搭建自己的桌面环境。

    应用、集成组件、shell 等都由你自己选择、安装和配置。

    本 wiki 的内容_非常_详尽。 在认定某项功能无法正常工作或不可用之前，强烈建议先仔细查阅本 wiki。

    说明

    NVIDIA GPU 往往无法开箱即用。 如果你打算使用 NVIDIA GPU，请在安装 Hyprland 后按照 NVIDIA 页面上的说明操作。 这得怪 NVIDIA。

    发行版 #

    我们在 Arch 和 NixOS 上运行并测试 Hyprland，并保证 Hyprland 能在这两个发行版上正常工作。 在其他发行版（不基于 Arch 或 Nix 的发行版）上，运行效果可能各不相同。 不过，Hyprland 采用的技术非常前沿，因此在 Pop!_OS、Fedora、Ubuntu 等定期发布新版本的发行版上运行时，会遇到严重问题。 openSUSE、Solus 等滚动发行版通常可以正常运行 Hyprland。

    安装 #

    安装 Hyprland 很简单。 用你的包管理器安装即可。

    强烈建议使用发行版为你打包的版本，不要手动编译或使用 -git 包。 Hyprland 的生态庞大，依赖关系错综复杂，手动编译可能会让你遇到依赖版本过旧或不兼容的问题。

    如果你因此遇到 .so 文件不匹配或缺失的错误，这完全是你自己造成的！ 请参阅这条常见问题解答。

    当然，如果你经验丰富，想参与新功能的测试，我们非常欢迎你运行最新的 Git 提交版本。 不过，遇到“.so 文件缺失”错误就别来问我们了！

    Nix 可以解决这个问题。 这种方法适合熟悉脚本运行的进阶用户。 如果你使用的发行版对 Hyprland 支持欠佳，可以考虑安装 Nix 包管理器。 它可以解决 .so 文件不匹配以及其他库冲突问题，并确保软件包保持最新。 所有使用 systemd 的发行版都支持 Nix，它不会干扰或取代你现用的包管理器。

    软件包 #

    警告

    Hypr* 团队不维护任何软件包。 如果软件包有问题，请先尝试从源码构建。

    标有 * 的发行版不受官方支持。 这些发行版的安装说明由社区维护，无法保证其准确性。

    Arch

    从 Arch 软件仓库安装带版本标签的正式发行版：

    sudo pacman -S hyprland
    自动从源码编译 #

    警告

    请先阅读安装一节中关于使用 -git 包或从源码编译的警告！

    从 AUR 安装时会编译最新源码：

    yay -S hyprland-git

    你也可以安装 hyprland-meta-git 包，自动获取并编译 hypr* 生态中所有组件的最新 Git 版本。

    yay -S hyprland-meta-git

    警告

    使用 -git 版本时，每当 hyprutils 等直接依赖项的更新破坏 ABI 兼容性，你都需要重新编译 Hyprland 和所有其他依赖该组件的工具。 否则就会出现“.so not found”错误。

    如果你决定使用 AUR 中的 git 版本，可以从 Chaotic AUR 获取预编译的二进制包。 请注意，更新 hyprutils 等依赖项后，你可能仍需自行重新编译所有组件，因为 Chaotic AUR 不会自动完成这一步。

    说明

    你可以使用 downgrade 轻松回退到先前的 -git 版本。

    Nix

    请参阅 Nix 页面，了解如何安装 Hyprland。

    openSUSE*

    从快照 20230411 起，Factory 已收录 Hyprland。 使用 zypper 即可安装：

    sudo zypper in hyprland

    也可以通过 YaST2 Software 安装“hyprland”包。

    要让 hyprpm 识别其依赖项，还需要安装 hyprland-devel：

    sudo zypper in hyprland-devel

    你也可以按照手动构建一节的说明自行构建 Hyprland。

    说明

    Leap 不提供 Hyprland，因为它所提供的编译器以及 Hyprland 需要的大多数库都太旧了。

    Fedora*

    使用 lionheartp/Hyprland Copr 仓库。

    你也可以按照这里的说明自行编译。

    Debian*

    从 Debian 14（Forky）起，软件仓库已提供 Hyprland：

    sudo apt install hyprland

    Debian 13（Trixie）的 backports 仓库也提供 Hyprland：

    sudo apt install -t trixie-backports hyprland
    Gentoo*

    hyproverlay 提供 hypr 系列软件包。 使用以下命令启用这个 overlay：

    sudo eselect repository enable hyproverlay
sudo emaint sync -r hyproverlay

    然后即可安装 Hyprland：

    sudo emerge --ask gui-wm/hyprland

    这个 overlay 还提供 hyprlock、hypridle、xdg-desktop-portal-hyprland、hyprland-plugins、hyprpaper 和 hyprpicker 等软件包。 hyprwm/contrib 中的部分社区贡献脚本也有各自独立的软件包（如 app-misc/grimblast、app-misc/hdrop 等）。

    emerge --ask gui-apps/hyprlock
emerge --ask gui-apps/hypridle
emerge --ask gui-libs/xdg-desktop-portal-hyprland
emerge --ask gui-apps/hyprpaper
emerge --ask gui-apps/hyprpicker

    有关 USE 标志和更多细节，请参阅 Gentoo wiki 的 Hyprland 页面。

    FreeBSD*

    默认仓库提供 Hyprland 及相关软件包：

    • hyprland
    • hyprpaper
    • hyprpicker
    • xdg-desktop-portal-hyprland
    • 其他 Wayland 相关软件
    Ubuntu*

    Ubuntu 26.10（Stonking Stingray）的 universe 仓库 #

    Ubuntu 26.10 提供 hyprland 0.56.2，建议使用 apt 安装。

    sudo add-apt-repository universe && sudo apt update && sudo apt install hyprland

    警告

    Ubuntu 26.04 及更早版本提供的 hyprland 包极其陈旧。 强烈建议避免使用这些版本的软件包。 请手动构建整个软件栈。

    Ubuntu 26.04 LTS（Resolute Raccoon）的 universe 仓库 #

    sudo add-apt-repository universe && sudo apt update && sudo apt install hyprland

    Ubuntu 24.10（Oracular Oriole）的 universe 仓库 #

    sudo add-apt-repository universe && sudo apt update && sudo apt install hyprland
    Alpine*

    Alpine 的 community 仓库目前提供 Hyprland，由社区维护。

    以下命令会安装 Hyprland 及其依赖项。

    apk add hyprland
    Void Linux*

    由于打包理念存在分歧，Void Linux 的官方仓库不提供 Hyprland。 不过，有一个第三方仓库提供通过 GitHub Actions 在持续集成流程中构建的二进制包。

    运行以下命令即可添加该仓库：

    sudo cp /usr/share/xbps.d/00-repository-main.conf /etc/xbps.d/
sudo sed -i "1i repository=https://mirror.black-hole.dev/$(xbps-uhelper arch)" /etc/xbps.d/00-repository-main.conf

    然后就可以像安装其他软件包一样安装这些包：

    sudo xbps-install -S hyprland
sudo xbps-install -S hyprland-devel # 如果要使用插件
sudo xbps-install -S xdg-desktop-portal-hyprland

xbps-query -Rs hypr # 执行此步前，需要先使用 xbps-install -S 接受软件仓库的指纹

    更多信息请参阅 hyprland-void README，其中也说明了如何使用提供的模板为 Void Linux 手动构建 Hyprland。

    Ximper*

    从 Sisyphus 安装：

    epmi hyprland
epmi hyprland-devel # 如果要使用插件

    安装生态系统中的相关组件：

    epmi xdg-desktop-portal-hyprland
epmi hypridle
epmi hyprpaper
epmi hyprpicker
    Solus*

    在 Solus 上运行：

    sudo eopkg install hyprland

    说明

    如果你打算使用插件，请注意，某些发行版可能会将 hyprpm 单独打包。

    使用 CMake 构建 #

    git clone --recursive https://github.com/hyprwm/Hyprland
cd Hyprland
make all && sudo make install

    启动时崩溃 #

    请参阅崩溃与缺陷。

    自定义安装（调试构建等） #

    1. 用 cd 进入 Hyprland 仓库目录。
    2. 如需构建调试版本： 
      make debug
sudo make install
    3. 如需使用其他构建配置，请将 <PRESET> 替换为所选预设（release 或 debug）： 
      make <PRESET> && sudo cp ./build/Hyprland /usr/bin && sudo cp ./example/hyprland.desktop /usr/share/wayland-sessions

    自定义构建标志 #

    要使用自定义构建标志，需要跳过 make，直接使用 CMake。

    CMake 支持以下自定义构建标志：

    NO_XWAYLAND - Removes Xwayland support
NO_SYSTEMD - Removes systemd dependencies
NO_UWSM - Does not install the hyprland-uwsm.desktop file
NO_HYPRPM - Does not build and install hyprpm

    可以这样向 CMake 传递标志：

    cmake --no-warn-unused-cli -DCMAKE_BUILD_TYPE:STRING=Release -D<FLAG>:STRING=true -B build

    将 <FLAG> 替换为其中一个自定义构建标志。 要同时使用多个标志，可以继续添加 -D<FLAG_2>:STRING=true。

    也可以将 BUILD_TYPE 改为 Debug。

    运行以下命令进行构建：

    cmake --build ./build --config Release --target all -j`nproc 2>/dev/null || getconf NPROCESSORS_CONF`

    如果配置时选择了 Debug，也要将 --config 的值改为 Debug。

    运行以下命令进行安装：

    sudo cmake --install ./build

    在虚拟机中运行 #

    实际效果可能因环境而异，官方不支持这种运行方式。

    通读 ArchWiki 的 libvirt 页面，安装并配置好 libvirt、virsh 和 virt-viewer。

    # 安装 libvirt 和 qemu 相关软件包。
sudo pacman -S libvirt virt-viewer qemu-common
# 将自己的用户账户加入 libvirt 组。
sudo usermod -a -G libvirt USER # 将 'USER' 替换为你的用户名。
# 启用并启动 libvirtd。
systemctl enable --now libvirtd

    前往 GitLab 上的 arch-boxes 仓库，下载最新的 Arch QEMU 基础镜像。 也可以从任意 Arch 镜像站下载。

    curl https://geo.mirror.pkgbuild.com/images/latest/Arch-Linux-x86_64-basic.qcow2 \
  -o ~/Downloads/arch-qemu.qcow2 # 也可以将其下载到任意位置。

    使用 virsh 创建虚拟机。

    # 使用 virt-install（随 libvirt 提供）从镜像安装虚拟机。
virt-install \
  --graphics spice,listen=none,gl.enable=yes,rendernode=/dev/dri/renderD128 \
  --name hypr-vm \
  --os-variant archlinux \
  --memory 2048 \
  --disk ~/Downloads/arch-qemu.qcow2 \
  --import

    使用 virt-viewer 连接，它会在 TTY 上打开图形会话。 默认用户名和密码都是 arch。

    警告

    务必使用 --attach 标志，因为启用 virgl 后必须禁用监听。 因此，无法通过 TCP 或 UNIX 套接字直接连接到远程显示。 --attach 会请求 libvirt 提供一个已连接到远程显示的套接字。*

    virt-viewer --attach hypr-vm

    最后，在虚拟机内按照上文的说明从 AUR 安装 hyprland-git 或手动构建。

    警告

    务必安装 mesa 作为 OpenGL 驱动。 mesa 包含 virgl 驱动。
